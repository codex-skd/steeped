<h2>v0.0.0-beta.1 - First release: Simply Tea on NeoForge 1.21.1</h2>

<p>First public build of <strong>Steeped</strong>, a NeoForge 1.21.1 port of <strong>Simply Tea</strong> by Elucent and KnightMiner (MIT).</p>

<h3>Features</h3>
<ul>
<li><strong>Tea trees</strong> that generate in forest biomes, with saplings, trunks, and matching fences and fence gates.</li>
<li><strong>Teapots</strong> that hold water or milk and can be boiled over a campfire or in a furnace.</li>
<li><strong>Drinks</strong>: green, black, dandelion, chai and chorus tea, apple iced tea and hot chocolate, with optional honey and cinnamon, plus tea bags.</li>
<li><strong>Five effects</strong>: Restful, Relaxed, Caffeinated, Invigorated and Enderfalling.</li>
<li><strong>Ice cubes</strong> and <strong>chorus petals</strong> added to loot through global loot modifiers.</li>
<li>Recipes, tags, loot tables, worldgen and a server config for drinks, teapots and trees.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Ported from Forge 1.20.1 to NeoForge 21.1.249 (Minecraft 1.21.1, Java 21).</li>
<li>Own id <code>steeped</code>: recipes and datapacks written for the original <code>simplytea</code> are not compatible.</li>
<li>The drink config is <code>COMMON</code>. Hunger and saturation use the config defaults when the items are registered (food properties are immutable in 1.21); effect times and levels read the config when drinking.</li>
</ul>

<blockquote>
<strong>Beta:</strong> the dedicated server starts cleanly and all data loads, but gameplay (tree generation, teapot behaviour, effects, rendering) has not been tested in a client yet. Please report anything odd.
</blockquote>
